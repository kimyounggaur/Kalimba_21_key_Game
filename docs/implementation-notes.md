# 구현 결정 기록

2026-11-10 (한국 시간).

- 시작 시 대상 저장소 main은 비어 있었습니다. 기존 코드·사용자 변경이 없어 React/TypeScript/Vite 기본안을 적용했습니다. Node24에서 lockfile을 생성했습니다.
- 원문의 키·점수·별·5곡·12레슨·고양이 조건을 유지했습니다. 실시간 소리는 React 상태 갱신과 분리했습니다.
- 실제 칼림바 녹음이 제공되지 않아 21음 절차 합성 WAV를 제작하고 출처를 manifest와 설정에 표시했습니다. 녹음 음질 검수 완료로 표시하지 않습니다.
- 원본 이미지는 보존하고 투명 강조·입력 영역을 겹쳤습니다. 확대 악기는 연속 물리키 순서의 벡터이며 사이 키를 생략하지 않습니다. 독립 원본 키 분리와 키 자체 애니메이션은 후속 자산 작업입니다.
- 세로 큰 버튼은 360px 이상3×7, 미만4×6입니다. 일반 모바일의 오버레이 스크롤바와 다른 데스크톱 iframe 환경도 확인했습니다. UI 테스트용 임시 iframe 페이지는 배포 전 제거합니다.
- 속도를 바꾸고 재개하면 혼합된 시각의 점수가 남지 않도록 선택한 곡/구간 처음부터 새 판정으로 시작합니다. 일반 중단은 현재 두 마디를 재시작하고 앞 구간을 유지합니다.
- 실제 기기가 없는 환경에서는 기능 테스트를 진행하고 실기기 항목을 미검증으로 기록합니다.
- 로그인·마이크·온라인 랭킹·결제·PWA·교사 편집기는 설계 범위대로 추가하지 않았습니다.
