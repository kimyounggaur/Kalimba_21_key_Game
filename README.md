# 고양이의 칼림바 정원

21키 칼림바를 터치하며 짧은 멜로디를 익히는 모바일 웹앱입니다. 제공된 고양이 패턴 칼림바를 바탕으로, 자유 연주 → 기다려 주는 따라 연주 → 박자에 맞춘 곡 도전을 연결했습니다.

## 실행

Node.js 22.12 이상(개발 검증: 24.22.1)이 필요합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm run validate:content
npm run test:unit
npm run build
npm run preview
```

`dist`를 Vercel 등 정적 호스팅에 배포합니다. 로그인·서버·환경변수 설정은 필요하지 않습니다. 검수용 브라우저 자동화는 개발 환경의 브라우저 도구로 수행했으며, 실제 기기 검수와 구분합니다.

## 기능

- F3–E6 C장조 21키. 중앙 k11=F3, C4=k13. 숫자 악보의 점으로 옥타브를 표시합니다.
- 원본 악기 전체, 연속 음역 확대, 21개 큰 버튼. 좁은 화면은 3×7 또는 4×6 버튼입니다.
- 포인터별 터치, 두 음 화음, 키보드 방향키 선택 및 Enter/Space 타격. 홀드와 release는 재발음하지 않습니다.
- 5개 원작 연습곡과 12개 레슨, 시범, 느린 속도, 현재/다음 음 안내, 두 마디 반복.
- Web Audio 출력 시계, 16박 지연 보정, 4박 카운트인, 중단 시 현재 두 마디부터 재시작.
- 음과 리듬을 구분하는 점수, 세 가지 별, 복습, 고정 슬롯의 고양이 5종.
- IndexedDB 진도·시도·고양이 저장. 결과 및 보상은 하나의 트랜잭션으로 기록하고 중복 지급을 방지합니다.
- 음량·라벨·메트로놈·동작 줄이기·집중 화면·도움말.

## 사용

처음 방문하면 ‘소리 켜고 시작하기’를 누릅니다. 휴대폰에서는 큰 버튼이 기본입니다. ‘따라 연주’는 올바른 음을 누를 때까지 기다립니다. 두 음 화음은 기본 순차 확인 또는 레슨11의 400ms 함께 누르기로 연습합니다. ‘곡 도전’은 타격 시점만 채점하며, 길게 누른 시간을 음표 길이로 평가하지 않습니다.

곡 전체의 따라 연주 완료, 또는 도전에서 정답음 절반 이상 확인 시 해당 고양이가 정원에 찾아옵니다. 부분 반복·시범·무입력에는 완주 보상을 지급하지 않습니다. 브라우저 데이터를 지우거나 다른 기기를 사용하면 진도가 자동 이전되지 않습니다.

## 소스와 자산

- `src/domain/content.ts`: 단일 조율, 5곡 이벤트와 12레슨.
- `src/engine/`: 오디오, 판정, 기다림 상태와 transport.
- `src/storage/`: IndexedDB 및 멱등 보상.
- `src/components/`: 악기, SVG 고양이, 보정 화면.
- `docs/kalimba-design.md`, `docs/kalimba-promptbook.md`: 제공 설계와 실행 순서.
- `docs/implementation-status.md`, `docs/qa/acceptance.md`: 구현 상태 및 확인 범위.
- `public/audio/manifest.json`: 음원별 출처와 해시. `python3 scripts/generate-audio.py`로 재생성합니다.

음원은 이 프로젝트에서 제작한 물리 모델 **합성 칼림바 21음**이며 실제 악기 녹음은 아닙니다. 사용자 칼림바 그림은 원본을 보존하고 강조 레이어를 씌웠습니다. 원본 키가 분리된 것처럼 움직이는 효과는 적용하지 않았습니다. 고양이 SVG는 앱에서 직접 그린 벡터입니다. 현재 음원 3.705MB, 디코드 약7.409MB입니다.

실제 iPhone/Android의 멀티터치, 블루투스·스피커 음질, 물리 출력 지연과 장시간 수업 사용은 실기기 검증이 필요합니다. 데스크톱에서 폭을 맞춘 검수를 실제 휴대폰 검증으로 간주하지 않습니다.
